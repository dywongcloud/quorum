# QUORUM project

Use the gm skill and the connected gm verbs for project work, including
delegated work. Route discovery through `codesearch` and git operations through
the git verbs. Attribute commits only to the authenticated GitHub user.

The distributable skill lives in `skills/quorum/`. `.agents/skills/quorum` is a
relative link to it for workspace discovery. Keep the YAML frontmatter and
`agents/openai.yaml` consistent with the `quorum` name. The complete Mermaid
graph lives in `references/anchor-graph.md`; it is generated by
`tools/build_graph.py`, and `scripts/validate_graph.py` refuses any drift.

`skills/quorum/SKILL.md` is the contract. It keeps DADA's five required
artifacts, the living Frontier, the no-move-quota rule, independent contrasting
critics, objection resolution, and re-measurement of every printed figure. The
modes are Fail-Closed and Graceful. Stop conditions S1 through S8 include the
crucible push, the jank checksum, axiom discharge and replay idempotence.

The `EPISTEMIC_AUDIT_DAEMON` in `skills/quorum/scripts/epistemic_audit.py` is
the executable form of the closed-loop contract. It has four fault codes, a
frozen State, pure derivation, and a self-falsification loopback. It emits JSON
only. Do not add a default-value path for an unbound symbol: an unmapped query
must return `[FAULT: STATE_UNMAPPED]` with the missing name.

## Single-writer surfaces

Concurrent agents each own disjoint files. A panel seat writes exactly one file,
`panel/<round>/<seat>.md`. Batches hold at most three seats. A verdict is a
file, not a return value; `collect_panel.py` decides whether a quorum exists.
No seat reads another seat's verdict before filing its own.

## Verification

Verification is live execution against the real artifact, same turn as the
work. No test files, no mocks, no synthetic fixtures, no elision markers in
source, no admit/deferral markers, no graphical glyphs in source lines, no hedge
language, no secrets, and no unchecked panics. Run all four validators and
`verify_invariants.py --all` before recording a Compliance Check. Re-run them
after the last edit so no recorded digest is stale.

Do not publish local gm state, machine configuration, credentials, or the
generated traversal log. `QUORUM-CARRY-FORWARD.md` is durable project knowledge
and is committed.

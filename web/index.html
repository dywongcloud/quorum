QUORUM derives a distributed design from a bounded state payload, then tries to falsify its own derivation. No interpolation. No vibes. No truncation.

01 / WHAT IT IS

A design agent that argues against itself

DADA traverses an anchor graph of graphic-design literature with a panel of art critics. QUORUM keeps the machinery and replaces the domain: a 400-node graph built from Site Reliability Engineering, Designing Data-Intensive Applications, the impossibility results, the systems papers, and the operations canon. Its critics are the authorities who wrote them.

Each move is a state transition. Each transition is derived, not asserted. A quorum of independent critics examines the measured artifact, and any one of them can stop the line. The run closes only when the frontier is empty, the quorum passes, and every axiom has a live witness.

03 / PANEL

One seat per authority

A critic named for two thinkers is two agents, not one composite voice. Fischer, Lynch and Paterson sit separately, each arguing from the FLP paper alone. Clarke and Emerson sit separately on model checking. Susan Leigh Star and Geoffrey Bowker object when the human labor behind the infrastructure is erased from the diagram.

Dotted edges join counterpoints: proof against experiment, safety against liveness, transactions against convergence. A seat on a panel pulls its partner onto the panel. That closure is computed from the graph, not assembled by hand.

A round without every required verdict has no quorum. A missing seat is NOT REPORTED, never PASS.

04 / INSTALL

Three steps

  1. 1

    Clone the repository, or add the skill from the repository URL with your skills CLI.

  2. 2

    Confirm the workspace discovery link resolves and run python3 -I scripts/validate_skills.py.

  3. 3

    Invoke $quorum with a distributed-systems design brief. The run writes the five artifacts into QUORUM-LOG.md.

Requires Python 3.10 or later for the graph walk and audit daemon. PyYAML 6.0.2 is required only by validate_skills.py. No network access is needed after the skill is installed.
